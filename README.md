# 🌍 Wanderlust — Full‑Stack Travel Website

**A pure website built from scratch using Node.js, Express, EJS, and MongoDB (via Mongoose).**  
This project demonstrates end‑to‑end web development skills in JavaScript, server‑side rendering, and database integration — aligning with modern web development requirements.

---

## 🚀 Project Overview

**Frameworks & Libraries**
- **Node.js** — backend runtime environment for JavaScript.  
- **Express.js** — lightweight web framework for routing and middleware.  
- **EJS (Embedded JavaScript Templates)** — server‑side rendering engine for dynamic HTML views.  
- **Mongoose** — ODM (Object Data Modeling) library for MongoDB integration.

**Database**
- **MongoDB Atlas** — cloud‑hosted NoSQL database.  
- Used with **Mongoose** for schema definition, validation, and CRUD operations.

**Features**
- User‑friendly travel website interface.  
- Dynamic pages rendered with EJS templates.  
- Full CRUD functionality for destinations, reviews, and user data.  
- Responsive design with clean UI.  
- Built entirely from scratch — no boilerplate frameworks.
